## Enunciado

> Desafio proposto pela comunidade **Tech Sisters** (Desafio do Código).

Pratique a coleta, leitura e armazenamento de dados de entrada, trabalhando com a declaração de variáveis de diferentes tipos (**String**, **Inteiro**, **Decimal/Float**) e exercitando a verificação/exibição dinâmica do tipo de dado de cada variável no console.

Crie um programa que peça ao usuário seu **nome**, **idade**, **altura** e **cidade**. Imprima o tipo de cada variável e, em seguida, imprima as informações na tela.

**Critérios**

1. Receber e armazenar o nome, idade, altura e cidade digitados pelo usuário.
2. Verificar e imprimir o tipo de dado de cada variável utilizada.
3. Imprimir uma mensagem final combinando todas as informações coletadas de forma clara.

---



## Resumo

Ler nome, idade, altura e cidade digitados pelo usuário, identificar o tipo de dado de cada variável e exibir uma mensagem final com todas as informações.

**Conceitos praticados:** `Scanner` · `String` / `int` / `double` · declaração de variáveis · saída formatada
